# wyblogs 网络爬虫工具

专为 `https://wyblogs.eu.org/` 定制的多功能数据采集与下载工具。支持全站/专区批量抓取、**关键词全网精准检索**、**多选指定下载**、**外链视频真·自动解析下载 (MP4)**、**搜索清单导出**与**搜索历史记录管理**。

---

## ✨ 主要功能

1. **外链视频自动化解析与下载（新特性）**：
   - **VOE 直链秒解**：逆向跳转与 `/download` 终结点，绕过广告弹窗，直接提取 1080p/720p 真实无损原画 MP4 直链高速下载。
   - **Luluvid 混淆流逆向 + FFmpeg 转码**：内置通用 Dean Edwards Packer 还原算法，秒解带签名 `master.m3u8`，配合内置静态免安装 `ffmpeg`，直接将 HLS 切片无损封装并合成为本地 `.mp4` 文件。
   - **网盘直链转换**：自动将 Pixeldrain 等网盘分享页转换为官方高速 API 直链下载。
   - **Playwright 浏览器自动化嗅探兜底**：利用内置 Chromium/Edge 内核，无感拦截未知或强防护站点的媒体流数据。
   - **智能多源分段去重**：同一视频分段（如 Part 01）存在多个镜像备用源时，优先从最快源拉取，成功后自动跳过冗余源，绝不重复下载。

2. **关键词搜索与指定下载**：
   - 调用目标站点原生搜索接口，支持全站或按板块过滤（小说、写真、视频、海棠等）。
   - 终端支持**分页浏览**匹配结果（每页 15 条，支持 `n` 下一页、`p` 上一页）。
   - 支持强大的**多选语法指定下载**：单选 `1`、离散多选 `1,3,5`、范围选择 `2-6`、混合输入 `1, 3-5, 8` 或全选 `all`。
   - 支持一键导出当前搜索结果清单为独立 CSV 表格文件（输入 `e` 或 `--export-search`）。
   - 智能识别板块类型，按需提示是否下载写真套图或 MP4 视频。

3. **专区自选下载**：
   - 浏览分类板块（小说、写真、视频等）时，提供两种模式切换：
     - `[1] 批量抓取整页全部文章`
     - `[2] 预览文章列表并自选下载`：实时拉取该页文章标题与字数，自由勾选想要下载的篇目。

4. **搜索历史记录管理**：
   - 搜索词本地持久化保存，再次搜索时可直接输入序号快捷选用。
   - 提供专属管理菜单，支持一览历史关键词或一键安全清空。

5. **小说板块抓取**：
   - 自动过滤网页中的广告代码（`<ins>` 广告块及 JS 广告脚本）。
   - 提取完整小说正文、字数、阅读时长、分类与标签。
   - 自动保存为排版清晰的独立 `.txt` 文件（支持 Windows/Linux 文件名自动脱敏）。

6. **写真板块抓取**：
   - 支持解析懒加载真实的图片高清地址（支持本地与外部图床）。
   - 自动提取各类网盘下载链接（Krakenfiles、Pixeldrain、1024terabox、Files.fm 等）。
   - 可选 `--download-images` 开关，批量将写真套图下载至独立相册文件夹。

7. **运行方式**：
   - **交互式控制台菜单**：直接双击或运行 `python main.py`，全中文编号提示，零门槛使用。
   - **命令行模式（CLI）**：支持自动化脚本调用、并发配置、自定义输出目录。

## 🛠️ 安装与依赖

进入爬虫项目目录并安装依赖：

```bash
cd wyblogs-crawler
pip install -r requirements.txt
```

## 🚀 使用指南

### 1. 交互式菜单（推荐新手）

直接在终端运行以下命令：

```bash
python main.py
```

终端将弹出交互主菜单：
```text
============================================================
      wyblogs (https://wyblogs.eu.org/) 专门爬虫工具      
============================================================
  [1] 抓取【小说专区】(自動排版保存纯净 TXT 小说，过滤广告)
  [2] 抓取【写真专区】(提取原图、网盘下载链接，可下载图片)
  [3] 抓取【视频专区】(解析外链流媒体直链，可一键下载 MP4)
  [4] 抓取【海棠专区】(海棠耽美小说与短篇)
  [5] 抓取【全站最新】(按首页最新文章顺序爬取)
  [6] 抓取【单篇链接】(输入单个文章或小说 URL 直接下载)
  [7] 关键词搜索与指定下载 (全站精准检索并自选下载)
  [8] 管理搜索历史记录 (查看或清空本地历史)
  [0] 退出程序
============================================================
```

- 选择 `[3]` 抓取视频专区或选择 `[7]` 搜索视频时，程序会自动提示：
  `是否自动解析并下载真实 MP4 视频文件到本地？(y/N):`
- 输入 `y` 即可全自动下载保存为排版规范的 MP4 视频。

---

### 2. 命令行参数模式（CLI）

#### ① 视频专区抓取并自动下载 MP4 视频
```bash
# 抓取视频专区第 1 页并下载其中的全部真实 MP4 视频
python main.py --type video --pages 1 --download-videos

# 浏览视频专区第 1 页，仅下载第 1 篇的真实视频
python main.py --type video --pages 1 --select 1 --download-videos
```

#### ② 关键词搜索并自选下载（小说/写真/视频通用）
```bash
# 搜索关键词并下载第 1 到第 3 篇（若包含视频自动下载 MP4）
python main.py --search "男神" --select 1-3 --download-videos

# 仅将搜索结果列表导出为 CSV 清单表格
python main.py --search "男神" --export-search
```

#### ③ 写真与小说专区批量抓取
```bash
# 批量抓取写真专区第 1 页并下载高清套图
python main.py --type photo --pages 1 --download-images

# 批量抓取小说专区第 1-2 页全部小说
python main.py --type novel --pages 1-2
```

#### ④ 单篇 URL 抓取（全自动识别小说/写真/视频）
```bash
python main.py --url "https://wyblogs.eu.org/posts/xxx.html" --download-videos --download-images
```

## ⚙️ 高级配置 (`config.py`)

在 `config.py` 中可以自由调节：
- `REQUEST_DELAY`: 请求间隔秒数（默认 0.3s，降低爬取频率保护目标服务器）。
- `DEFAULT_WORKERS`: 默认线程池并发数量（默认 4）。
- `TIMEOUT`: 超时时间（默认 25s）。
- `DEFAULT_HEADERS`: 自定义 User-Agent 或 Cookie。
